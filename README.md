# Weather-App- 🌦️-P10
A clean, responsive weather application built with HTML, CSS, and JavaScript that displays current weather conditions for any city worldwide.


✨Features:
1️⃣Real-time weather data from OpenWeatherMap API
2️⃣Displays temperature, humidity, and wind speed
3️⃣Dynamic weather icons based on conditions (sunny, rainy, cloudy, etc.)
4️⃣Error handling for invalid city names
5️⃣Responsive design
6️⃣Clean, minimalist UI


🔷Technologies Used:
Frontend: HTML5, CSS3, JavaScript

API: OpenWeatherMap (free tier)


✔ How It Works
Enter a city name in the search box

Get instant weather information including:

Current temperature (°C)

Humidity percentage

Wind speed

Visual weather representation
